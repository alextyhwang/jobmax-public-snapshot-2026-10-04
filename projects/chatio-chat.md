# Chatio Chat

## Resume Bullet Bank
| Target Angle | Bullet |
|---|---|
| AI product | Built Chatio Chat, a self-hostable local-first AI chat interface supporting OpenAI, Anthropic, Google, xAI, DeepSeek, and 300+ OpenRouter models through user-provided API keys. |
| Local-first/product trust | Engineered browser-first persistence with IndexedDB so conversations, settings, API keys, and chat modes stay local unless users explicitly export or share them. |
| Agent workflows | Created reusable chat modes combining system prompts, model presets, and tool configurations for Tavily search, NBA stats, Polymarket data, and computer-use workflows. |
| Full-stack product | Added optional Postgres-backed conversation/mode sharing and Cloudflare R2 image uploads while preserving a zero-config self-hosting path for basic use. |
| UX/model efficiency | Built context-window and cost visibility into the chat UI so users can understand token usage, model limits, and long-conversation tradeoffs in real time. |
| Product suite | Connected a live AI chat surface to Chatio's benchmark product, giving users a practical way to test, compare, and use model behavior beyond a leaderboard. |
