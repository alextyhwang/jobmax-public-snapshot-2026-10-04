# Project Vault

This is the master index for the candidate's projects. Keep this file high-level. Put detailed metrics, screenshots, stories, resume bullets, interview talking points, and proof links in the individual project files.

The goal is to make resume tailoring easy: choose the projects that best match a job, then pull the strongest evidence and bullet options from each project's brag sheet. Work/research achievements live in [../experience](../experience), and leadership achievements live in [../leadership](../leadership).

## How To Use This Folder

1. Start with the job description.
2. Pick 2-3 projects from the tailoring matrix.
3. Open each project file and choose the strongest proof points.
4. Pull only the bullets that match the role.
5. Keep exact metrics and claims source-aware; mark anything unverified before using it externally.

## Project Detail Standard

Each project file should include:

- One-line positioning.
- Role and ownership.
- Stack.
- Links.
- Achievement bank.
- Resume bullet bank.
- Interview story bank.
- Evidence and source notes.
- Open TODOs for missing metrics or proof.
