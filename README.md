# JobMax — public snapshot

A frozen, sanitized copy of the JobMax career workflow repository, with resume materials retained. Read [PUBLIC-SNAPSHOT.md](PUBLIC-SNAPSHOT.md) for the capture time and sanitization scope.

Source and workflows live in `scripts/`, `tools/`, `agents/`, and `.agents/`. Resume materials live in `profile/resume/`, `resumes/roles/`, and `output/pdf/`. Operational application and outreach data is empty.

Requires Node.js 22 or newer. Run `npm test`, `npm run tracker:check`, and `npm run outreach:check` to validate the source and empty records.
