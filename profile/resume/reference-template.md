## Layout Guidance

- Keep the resume exactly one page.
- Use a dense, readable one-page layout similar to the reference PDF.
- Prefer sans-serif typography over the old serif LaTeX look.
- Do not leave a large empty lower section when supported, relevant achievements can fit.
- If there is room, restore strong supported bullets before calling the PDF final.
- Preserve ATS-readable text and simple LaTeX structure.
- Spell out the LinkedIn, GitHub, and personal-site destinations in the header without `https://`; keep `portfolio.example.com` as the canonical personal-site link and keep `chatio.dev`, `wordhunt.org`, and other product URLs in their project rows.
- Always state in the Summary that the candidate is seeking a software engineering internship/co-op for Spring and/or Summer 2027; do not place this as a separate header tagline.

## Content Density Guidance

When space allows, include the strongest extra detail in this order:

1. Paychex AI-team/internal developer-tool rollout details and 55% token-usage reduction from the subagent architecture.
2. Real Wave production metrics: 100+ daily users, roughly 50% token spend reduction, 25% endpoint response improvement, 6,000+ weekly requests.
3. Chatio details: ~500-prompt benchmark, SSE streaming, tool calling, dynamic parameter optimization, IndexedDB/Cloudflare R2, 95% image storage reduction.
4. Bay Area Stem Academy full leadership proof: 660+ students, 15+ free camps, 5+ partner schools, $35,000+ in free STEM education, $5,000+ donated, SanDisk collaboration.
5. RIT Asian Culture Society if space remains and collaboration/community leadership helps the role.

## Paychex Default Framing

Lead with AI-team, platform ownership, LLM evaluation, and context-efficiency impact.

Preferred bullets:

- Led development of an internal AI developer platform on the AI Integrations team that integrated AI agents and MCP tooling into enterprise developer workflows; presented it to executives.
- Built a custom LLM evaluation harness for developer and Sales workflows to assess model reliability and usefulness.
- Reduced token usage by 55% with a subagent architecture while improving internal agent workflow performance.

Jenkins/CI/CD can remain a secondary skill or lower-priority bullet only when the job description specifically values CI/CD.
