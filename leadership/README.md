# Leadership Vault

This is the master index for the candidate's leadership, nonprofit, campus, and community work. Keep this file high-level. Put detailed metrics, stories, resume bullets, evidence, and open questions in the individual leadership files.

The goal is to make leadership easy to use in resumes, outreach, essays, interviews, and founder/operator positioning without cramming every detail into the main profile.
