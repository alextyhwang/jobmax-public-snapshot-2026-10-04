# Status Update Playbook

Use this playbook when asked for a progress summary.

## Sources To Check

| Source | What To Look For |
|---|---|
| `plan/big-picture.md` | Current phase and roadmap |
| `profile/profile.md` | Any stale positioning or missing profile data |
| `projects/` | New metrics, proof points, resume bullets, and project TODOs |
| `experience/` | Work/research achievements, resume bullets, and missing evidence |
| `leadership/` | Leadership metrics, stories, resume bullets, and missing proof |
| `outreach/*.md` | Ready contacts, due follow-ups, replies, and blocked research |
| `applications/` | Application statuses, deadlines, referrals, interviews |
| `reviews/` | Weekly progress and recurring blockers |

## Summary Format

Keep status updates short and action-oriented.

| Section | Include |
|---|---|
| Current focus | The most important active goal |
| Progress | What changed since the last update |
| Due now | Follow-ups, applications, or prep that need action |
| Risks | Missing information, stale follow-ups, weak pipeline areas |
| Next actions | The smallest set of useful actions to take next |

## Rules

- Do not rewrite the roadmap during a status update unless asked.
- Do not mark outreach as completed without evidence in the company file.
- Include exact dates when discussing follow-ups or deadlines.
- Prefer concrete next actions over motivational summaries.
