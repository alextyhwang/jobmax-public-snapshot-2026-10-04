## Full Job Description

HP IQ is HP’s AI innovation lab. SWE Intern on the Systems team builds low-level software close to hardware for intelligent product experiences. Work across the stack: performance bottlenecks, memory/resource management, data/sensor pipelines, build systems and tooling, debug system-level issues, partner with firmware/EE.

Key signals: C/C++, systems concepts (memory, OS, concurrency, architecture, performance), complex software from coursework/internships/projects. Preferred: modern C++, Android/AOSP, Linux kernel drivers, hardware accelerators, ARM SoC, bare-metal firmware. Pay ~$45–$51/hr.
