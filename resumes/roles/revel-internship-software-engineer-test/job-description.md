## Full Job Description

## About Revel
At Revel, we are revolutionizing the way the world’s most critical hardware is controlled—across aerospace, automotive, energy, and manufacturing sectors. Our next-generation software stack combines an intuitive command/control interface, a specialized programming language tailored for hardware control, and a high-performance runtime environment. We empower engineers to build, test, and deploy critical systems rapidly, reliably, and safely.

 
## The Internship
As a Software Engineering – Test Intern at Revel, you’ll help build the infrastructure that allows us to continuously test software against real and simulated hardware.

You’ll work at the intersection of software engineering, hardware, and infrastructure, helping build and maintain Hardware-in-the-Loop (HIL) test systems and the automation that powers them. You’ll write Python, work with CI/CD systems, interact with test equipment and hardware, and help make our testing faster, more reliable, and more scalable.

This is a hands-on internship for students who enjoy figuring out how systems work, automating repetitive processes, and solving problems that span software and hardware. You’ll work closely with experienced engineers and gain exposure to the infrastructure behind software used to control mission-critical hardware.

 
## What You'll Do
- Build and maintain Hardware-in-the-Loop (HIL) testing systems

- Write Python scripts and automation to improve software testing and development workflows

- Help integrate test equipment, instrumentation, and hardware into automated test environments

- Contribute to continuous integration (CI) and testing infrastructure

- Help diagnose and troubleshoot failures across software, hardware, and test infrastructure

- Improve the reliability, speed, and scalability of automated testing

- Develop tools and processes that make it easier for engineers to test software against real-world hardware

- Contribute to documentation and best practices around testing and automation

- Collaborate with software, embedded, and hardware engineers to improve test coverage and reliability

- Learn how software, infrastructure, and physical hardware come together in a production engineering environment
