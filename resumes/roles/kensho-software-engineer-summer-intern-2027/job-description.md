## Full Job Description

Kensho is S&P Global's hub for AI innovation and transformation. With expertise in machine learning, natural language processing, and data discovery, Kensho develops and deploys novel solutions for S&P Global and its customers. Focus areas include business and financial generative AI applications, agents, data retrieval APIs, data extraction, speech recognition, entity linking, document extraction, text classification, and NLP.

There are intern opportunities across various teams for Software Engineer interns. Some teams develop products and initiatives; others build systems and frameworks leveraged engineering-wide. Interns work in person from Cambridge HQ or New York City.

### What You'll Do
- Contribute to real features, gain feedback via code review, merge to the codebase, and deploy to production
- Learn and employ best practices such as static type checking, optimizing for legibility, code review, IaC, and following a maturity model for production-readiness
- Leverage Knowledge Days for continuous learning beyond day-to-day work

### Team-Specific Sampling
- Write server-side and user-facing applications built on top of machine learning capabilities
- Design interfaces, APIs, and services that address immediate needs with an eye for future scaling and reuse
- Develop abstractions to enable observability and deployment to the core platform
- Build data ingestion and processing for stand-alone software products and machine learning R&D

### What You'll Need
- At least one core expertise, such as distributed computing or deep knowledge of one of the technologies they use
- Practical understanding of algorithms, data structures, and design patterns
- Personal projects, open source contributions, or a portfolio of work
- Versatility and adaptability across teams/products
- Effective coding, documentation, and communication habits

### Technologies & Tools
- Python, Django, Typescript, Airflow
- Postgres, Elasticsearch, Kafka, Redis, Envoy
- AWS, Docker, Kubernetes, Terraform
- Git, Jenkins, Prometheus, Kibana, Grafana
