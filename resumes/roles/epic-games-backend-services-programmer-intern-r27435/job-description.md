## What We Do

Epic Games Services provides the plug-in connections between Unreal Engine 5, licensees, internal game teams, platform online services, and Epic Online Services. These services support cross-platform features including login, parties, voice chat, matchmaking, purchasing, cloud storage, and analytics.

## What You'll Do

The Backend Engineer Intern will join the team building systems that power Fortnite, including FNCS tournaments, storage for player cosmetics and Sprites, and persistence for LEGO Fortnite worlds. The intern will own a feature within the development cycle and participate in the team's day-to-day work.

- Contribute to backend systems that power Fortnite experiences.
- Learn about security, scalability, and maintainability in the code written.
- Collaborate with highly experienced engineers.
- Work with Fortnite product owners and producers on solutions for upcoming seasons.

## What We're Looking For

- Proficiency in Java or a similar object-oriented programming language.
- Experience with AI-assisted coding tools, such as Claude Code.
- Ability to communicate effectively and provide task updates in a remote-first team environment.
- Willingness to ask questions, seek guidance, and learn from feedback.
- Foundational analytical and problem-solving skills.
- Familiarity with cloud technologies, particularly AWS, is preferred.
- Familiarity with Unix-based systems is a plus.

The internship has a flexible start date in 2027. Recruitment is ongoing until teams find an ideal match. Applicants must be legally authorized to work in the posting location for the duration of the internship.
