## Full Job Description

Salesforce's Futureforce Tech Accelerator is an early hiring event that creates a fast track to interviews for Summer 2027 Software Engineering Internships. Selected applicants complete a HackerRank assessment and, if advanced, attend a mandatory in-person Salesforce headquarters experience in San Francisco from July 22-24, 2026.

Interns work with engineering teams on products, platforms, AI-powered experiences, and agentic technologies used by millions of people. The posting emphasizes mentorship, engineering training, recruiter support, and practical project work.

Required signals:

- Current student pursuing a BS in Computer Science or a related technical field.
- Returning to school after Summer 2027.
- Strong object-oriented programming/design, algorithms, data structures, and CS fundamentals.
- Hands-on experience or strong curiosity with AI-assisted development tools.
- AI-first mindset with comfort experimenting with prompting techniques and using AI to ramp up across the stack.
- Collaboration, communication, analytical thinking, and problem solving.

Preferred signals:

- Experience using and reviewing code or artifacts generated by LLM coding assistants and agentic tools.
- Ability to guide AI tools toward desired outcomes.
- SQL and relational database concepts.
- Java, JavaScript, web technologies, front-end and back-end languages.

Compensation listed by Salesforce: $43-$52/hour.
