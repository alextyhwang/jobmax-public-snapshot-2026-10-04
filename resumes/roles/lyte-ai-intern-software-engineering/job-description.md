## About Lyte

Lyte builds perception systems for Physical AI operating in complex environments. The company combines custom silicon, integrated sensors, and software into a unified platform for robotics, mobility, and next-generation automation. Lyte is headquartered in Sunnyvale, California, with a global presence.

## About the Role

Lyte is seeking a System Software Intern for a three-month internship to support the development and optimization of build infrastructure, CI/CD pipelines, and production automation. This hands-on DevOps-focused role works directly with Jenkins and GitLab pipeline infrastructure, build automation tooling, and development and deployment workflows used by hardware, firmware, and software teams.

## What You'll Do

- Develop and maintain CI/CD pipelines in Jenkins (Groovy-based declarative and scripted pipelines) and GitLab CI.
- Write and refactor Jenkins shared libraries in Groovy to standardize build, test, and release stages across projects.
- Build and maintain automation for software builds, regression testing, and hardware-in-the-loop test stations using Python and Bash.
- Manage and improve Jenkins agents, Docker-based build environments, artifact management, and pipeline reliability.
- Help migrate and consolidate pipelines between Jenkins and GitLab CI, improving speed, caching, and maintainability.
- Develop monitoring, logging, and pipeline-health dashboards.
- Troubleshoot build failures, flaky tests, and environment issues across embedded PetaLinux/FPGA and application software targets.
- Document pipeline architecture, deployment procedures, and operational best practices.
- Collaborate with hardware, firmware, and software teams in a fast-paced, distributed environment.

## Required Qualifications

- Currently pursuing a degree in Computer Science, Computer Engineering, Electrical Engineering, or a related field.
- Proficiency in Python and/or Bash scripting.
- Working knowledge of Linux/Unix environments and command-line tools.
- Familiarity with Git and standard version-control workflows.
- Basic understanding of CI/CD concepts covering build, test, artifact, and deploy stages.
- Hands-on exposure to Jenkins pipelines, Groovy, shared libraries, and/or GitLab CI/CD.
- Experience with Groovy or willingness to learn it for Jenkins pipeline development.
- Strong problem-solving skills, intellectual curiosity, and ability to learn new tools quickly.

## Preferred Qualifications

- Experience with Docker containers for reproducible build/test environments.
- Exposure to embedded Linux (Yocto/PetaLinux) or cross-compilation toolchains.
- Knowledge of monitoring/observability stacks such as Prometheus, Grafana, or ELK.
- Personal, open-source, or coursework projects involving automation or infrastructure.
