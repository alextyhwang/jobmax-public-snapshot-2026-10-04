## About the Co-Op

As an AI Platform Engineer Co-Op Intern, you’ll work alongside experienced platform and infrastructure engineers to help build the systems that power Brain Co.’s AI applications in production.

This internship is designed for current undergraduate students (junior or senior) who want hands-on experience contributing to real production systems, while receiving mentorship through code reviews, design discussions, and hands-on collaboration with the team. You’ll gain hands-on experience with cloud infrastructure, Kubernetes, distributed systems, observability, and the infrastructure behind modern AI workloads.

## What You’ll Work On

- Help build and improve Kubernetes- and Terraform-based infrastructure across production and customer environments.
- Contribute to tooling and automation that makes infrastructure easier and safer for engineers to deploy and operate.
- Work with cloud infrastructure, networking, CI/CD, and containerized systems.
- Help build and improve metrics, logging, tracing, dashboards, and monitoring for production services.
- Investigate performance and reliability issues across distributed systems and AI workloads.
- Support infrastructure for AI inference, data pipelines, and large-scale backend services.
- Participate in code reviews, architecture discussions, and technical problem-solving alongside experienced engineers.
- See the infrastructure you build support real applications used by customers at scale.
