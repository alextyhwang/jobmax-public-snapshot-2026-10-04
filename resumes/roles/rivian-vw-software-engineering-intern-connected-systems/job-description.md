## Role Summary
At RV Tech, we develop next-gen vehicle features that include remote commands from mobile apps, OTA software updates, real time vehicle telemetry, and fleet management tools. All of which rely on cloud, connectivity, and integration software working together at scale. As a Connected Systems intern, you will work on the backend services, integration layers, or connectivity infrastructure that keep vehicles talking to the cloud reliably. This may involve high throughput data pipelines, distributed cloud services, or the software that validates features work end to end across the vehicle.

Specific project areas vary by team and may include:

- Building and testing backend services that process vehicle telemetry and remote commands at fleet scale

- Developing event driven, distributed systems using tools such as Kafka, Kinesis, or Redis

- Contributing to cross domain systems integration and validation work, ensuring vehicle features function correctly end to end

- Supporting connectivity infrastructure, including the messaging and communication layers linking vehicle, mobile app, and cloud

- Working with cloud native infrastructure on AWS (EKS, Lambda, DynamoDB, IoT Core)

## Responsibilities
- Design, develop, and test software components within an existing distributed or connectivity system

- Write clean, maintainable code in Python, Go, C++, or Java depending on the team

- Participate in code reviews, design discussions, and debugging sessions with your team

- Contribute to test automation and validation for integration or connectivity features

- Document your work and present progress to your team throughout the internship

## Qualifications
Minimum:

- Currently enrolled in a Bachelor's or Master's program at an accredited US university

- Proficient in at least one of Python, Go, C++, or Java

Preferred:

- Actively pursuing a degree in Computer Science, Computer Engineering, Electrical Engineering, or a closely related field, with intent to return to school after the internship

- Exposure to distributed systems, event driven architecture, or cloud platforms, AWS preferred

- Familiarity with vehicle communication protocols such as CAN or MQTT, or IoT concepts

- Coursework or project experience with backend development, systems integration, or test automation
