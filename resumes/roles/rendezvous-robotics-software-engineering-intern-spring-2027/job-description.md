## Full Job Description

Full-time 12-15 week Spring 2027 software engineering internship in Golden, Colorado. The intern writes and tests flight software, builds ground-station tools for telemetry and command sequencing, develops changing-topology communication protocols, builds simulation environments, and debugs across software and hardware.

Key signals: C/C++, Python, networking and distributed-systems concepts, embedded Linux or bare-metal firmware, real-time systems, embedded communication buses, simulation, robotics or satellite projects, hardware/software collaboration, and ITAR eligibility.
