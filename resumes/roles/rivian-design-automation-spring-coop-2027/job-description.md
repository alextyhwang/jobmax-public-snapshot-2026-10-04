No Visa Sponsorship Accelerates EV Hardware Development: Developing custom automation scripts for Cadence tools eliminates repetitive manual tasks in schematic entry and routing, significantly speeding up the design cycles for Rivian's complex electronic control units. Reduces Costly Manufacturing Errors: Automated design rule checks and standardized component generation minimize human error in critical PCB layouts, preventing expensive hardware respins for high-stakes systems like battery management and infotainment. Optimizes Senior Engineering Bandwidth: Dedicating a Coop to build these specialized workflow tools frees up Rivian's senior hardware engineers to focus on core vehicle innovation and architecture rather than daily CAD tool management. Responsibilities Develop Custom Automation Scripts: Write and deploy SKILL, Python, and TCL scripts within Cadence Allegro and OrCAD to eliminate manual data entry during schematic capture and board routing. Integrate ECAD/MCAD Workflows: Create automated bridges between Cadence tools and mechanical CAD software to ensure accurate, real-time synchronization of complex EV packaging constraints and board outlines. Enhance Component Library Management: Build tools to automatically generate, verify, and update PCB footprint and schematic symbol libraries by syncing directly with Rivian’s Product Lifecycle Management (PLM) database. Implement Advanced Rule Checking: Program custom Design Rule Checks (DRCs) tailored to Rivian's high-voltage and high-speed signal integrity requirements, preventing manufacturing errors before tape-out. Deploy and Document Toolchains: Package the developed automation tools into user-friendly interfaces, write technical documentation, and train the hardware engineering team to adopt the new workflows. Qualifications Must be currently pursuing a bachelors or masters degree at an accredited university. Actively pursuing a degree or one closely related in computer science, electrical engineering, mechatronics, or similar. Possesses strong programming fundamentals with proficiency in Python, TCL, or C++, alongside an aptitude for learning proprietary EDA languages like Cadence SKILL. Demonstrates foundational knowledge of schematic capture and PCB layout processes, ideally with academic or project experience using Cadence OrCAD, Allegro, or similar ECAD platforms. Understands core hardware design principles, including component lifecycle management, basic signal integrity, and standard manufacturing constraints. Exhibits strong problem-solving skills with a track record of personal projects or coursework focused on software automation, API integration, or streamlining repetitive technical workflows.
