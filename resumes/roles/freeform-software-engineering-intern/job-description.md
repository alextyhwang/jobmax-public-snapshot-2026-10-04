## Full Job Description

Freeform builds software-defined autonomous metal 3D printing factories. Intern helps build core software for controls, high-speed data acquisition, and geometry processing pipelines that enable automated production.

Responsibilities: software for production-scale printing systems; integrate control algorithms with process/mechanical engineers; improve high-rate data acquisition/storage/retrieval; geometry-to-machine print instruction pipelines.

Basic: enrolled in CS/CE/EE (ABET); internship or engineering club with C/C++ or Rust. Nice: microcontrollers/FPGA/GPU, embedded/real-time, industrial automation/robotics, Linux. ITAR U.S. Person required. Pay ~$34–$38/hr by degree level. Hawthorne, CA facility.
