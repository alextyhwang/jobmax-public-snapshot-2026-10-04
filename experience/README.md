# Experience Vault

This is the master index for the candidate's work and research experience. Keep this file high-level. Put detailed metrics, STAR stories, resume bullets, evidence, and open questions in the individual experience files.

The goal is to make resume tailoring easier: given a job description, choose the most relevant experience bullets without rewriting the whole resume.

## How To Use This Folder

1. Read the job description.
2. Identify the strongest 1-3 experience themes.
3. Open the matching experience files.
4. Pull supported bullets from the bullet banks.
5. Keep dates, titles, organizations, and metrics accurate.

## Experience Detail Standard

Each experience file should include:

- Positioning.
- Snapshot.
- Responsibility bank.
- Achievement bank.
- Resume bullet bank.
- Interview story bank.
- Evidence and source notes.
- Open TODOs for missing metrics or proof.
