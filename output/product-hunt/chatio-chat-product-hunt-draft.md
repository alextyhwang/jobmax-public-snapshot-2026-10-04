## Maker comment

Hey Product Hunt, I built Chatio Chat because I wanted a fast AI chat app that did not make privacy, model choice, or self-hosting feel like afterthoughts.

It is an open-source, local-first chat interface for bringing your own API keys across OpenAI, Anthropic, Google, xAI, DeepSeek, and OpenRouter. The basic version needs no backend: conversations, settings, API keys, prompts, and chat modes stay in the browser through IndexedDB unless you explicitly export or share something.

The pieces I care most about:

- One interface for frontier models and 300+ OpenRouter models
- Reusable chat modes for prompts, model presets, and tool configs
- Optional tools for web search, NBA stats, prediction markets, and computer-use workflows
- Cost and context-window visibility while you chat
- Optional Postgres-backed sharing and Cloudflare R2 image uploads
- Apache-2.0 self-hosting path for people who want to run it themselves

This is the open-source chat app, separate from Chatio's benchmark work, though it can use Chatio model metadata to make model choice easier. I would love feedback from people who care about BYOK tools, local-first AI apps, and model comparison workflows.
