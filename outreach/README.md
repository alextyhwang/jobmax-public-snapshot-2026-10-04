# Outreach CRM

Draft voice and channel-specific templates live in [../profile/outreach-template.md](../profile/outreach-template.md). Use that file for LinkedIn messages, connection notes, email, X outreach, and follow-ups.

This folder tracks recruiters, engineers, alumni, founders, hiring managers, and warm leads by company.

## Status Values

Use these values consistently:

| Status | Meaning |
|---|---|
| Researching | Person is a possible lead, but details need verification |
| Ready | Profile is verified and ready for outreach |
| Contacted | First message or email sent |
| Follow-up due | Needs a follow-up |
| Replied | Person responded |
| Chat scheduled | Coffee chat, call, or meeting is scheduled |
| Connected | Relationship established or LinkedIn connection accepted |
| Referral path | Potential referral path exists |
| Blocked | Cannot proceed until a connection, reply, or missing detail changes |
| Closed | No further action needed right now |
